# Testing Guide

Use this guide before publishing or after changing data flow, plotting, slicing,
or large-data behavior.

## Automated Checks

Run from the repository root:

```powershell
python -m compileall -q main.py src test_data tests scripts
pytest
python test_data/verify_functions.py
python test_data/create_uxcase_test_data.py
python test_data/verify_uxcase_data.py
```

The `uxcase_*.npy` and `uxcase_mixed_suite.npz` files generated by the script
are ignored by git and can be deleted after manual testing.

## Smoke Fixtures

Tracked tiny fixtures:

- `test_data/test_1d.npy`
- `test_data/test_2d.npy`
- `test_data/test_data.npz`

These are only for fast loader and core-function checks. Use the generated
`uxcase_` suite for visual QA.

## UXCASE Manual Test Matrix

| File | Expected semantic | Recommended tests |
|---|---|---|
| `uxcase_signal_heartbeat_1d.npy` | 1D sequence | Line chart and histogram; repeated spikes should be visible. |
| `uxcase_well_log_table_2400x6.npy` | 2D table | Multi-line chart, column histogram, scatter, correlation heatmap, column filtering, CSV export. |
| `uxcase_fault_slice_image_512x512.npy` | 2D image/matrix | Heatmap/image display, colormap switch, X/Y swap, ascending/descending axes. |
| `uxcase_landcover_rgb_256x256x3.npy` | 3D multichannel | Channel heatmap/image for channels 0, 1, and 2. |
| `uxcase_seismic_volume_96x128x80.npy` | 3D volume | Slice heatmap, projection, 3D scatter, surface, wireframe, contour, voxel, slice stack. |
| `uxcase_reservoir_4d_48x64x40x4.npy` | 4D volume | Channel axis 3; inspect channels 0-3 with slice and projection plots. |
| `uxcase_stress_seismic_cube_192x256x160.npy` | Larger 3D volume | Drag open, background preview/statistics, cancel task, projection downsampling, one-click 2D view. |
| `uxcase_mixed_suite.npz` | Mixed NPZ | Switch every key and confirm semantic controls and shape ranges refresh. |

## Feature Checklist

- Drag-and-drop `.npy`, `.npz`, and `.zarr` sources.
- Zarr directory open: root arrays and grouped arrays appear in the key list.
- Dask-backed large arrays: preview/statistics/projection complete without
  materializing the full source array.
- Dimension filter: keep/drop `:`, comma indexes, slices, negative indexes, and
  singleton-axis removal.
- Universal slice: apply, reset, and combine with previous dimension filtering.
- Preview modes: auto, flat, 2D slice, axis summary.
- Statistics: sampled output appears for large arrays.
- Plot controls: image axis swap/order, volume slice axis/index, projection
  method, quality selection, 4D channel axis/index.
- Export: current 1D/2D view exports to CSV; high-dimensional views are guarded.

## Documentation Checks

Before publishing, search the repository for historical entrypoint names,
unfinished-documentation markers, and old-version launch instructions. The
search should return no active user-facing instructions.
